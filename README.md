# AI Backend Master Course (`Ai-Learning`)

An interactive **20-class AI backend curriculum** and visual-first slide deck built for vibe coders and non-tech beginners learning to architect and ship AI-powered backends.

## Tech Stack
- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Motion, Lucide Icons
- **Backend & AI:** Express, Google Gemini API (`@google/genai`)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure environment variables:**
   Copy `.env.example` to `.env` and add your Gemini API key.

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
